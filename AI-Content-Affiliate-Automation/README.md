# AI Content & Affiliate Marketing Automation

## Project Overview

This self-initiated portfolio project explores how AI and workflow automation can support product research, affiliate marketing, and digital content creation.

The workflow combines web research, product information extraction, AI analysis, and content generation.

## Workflow

```text
Product / Web Page
        ↓
     Firecrawl
        ↓
Product Information
        ↓
     AI Analysis
        ↓
Marketing Content
        ↓
Affiliate / Social Media Content
```

## Technologies Used

* n8n
* Firecrawl
* AI / LLM
* Web research
* Content automation
* Canva
* Pinterest
* Affiliate marketing

## Key Features

### Web Research & Data Extraction

Firecrawl is used to extract and read information from web pages, including product details and descriptions.

### AI Content Generation

AI analyzes the extracted information and helps generate product-focused marketing content.

### Affiliate Content

The workflow explores automated preparation of product descriptions and promotional copy for affiliate marketing.

### Social Media Content

The project explores preparing content for Pinterest and other social media channels.

## Project Purpose

This project was created as a self-initiated portfolio project to demonstrate how AI and automation can reduce repetitive product research and content-creation tasks.

It is not client or employer work.
