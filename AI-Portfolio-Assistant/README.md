# AI Portfolio Assistant

## Project Overview

The AI Portfolio Assistant is a self-initiated project that connects an AI assistant to my personal portfolio website through an n8n workflow.

The project demonstrates how AI can be integrated into a website to provide interactive information about projects, skills, tools, and professional background.

## Workflow

```text
Portfolio Website
        ↓
    User Message
        ↓
      n8n Webhook
        ↓
      AI Agent
        ↓
    AI Response
        ↓
    Website User
```

## Technologies Used

* n8n
* AI / LLM
* OpenRouter
* Webhooks
* API integration
* HTML / CSS / JavaScript
* Personal portfolio website

## Key Features

### AI-Powered Conversations

The assistant can respond to questions about my professional portfolio, projects, skills, and tools.

### n8n Integration

Website messages are sent to an n8n webhook and processed through an AI workflow.

### AI Agent

The workflow uses an AI agent to generate contextual responses.

### Website Integration

The assistant is connected to my personal portfolio website.
